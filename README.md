# Legacy Bot - Um legado que construimos juntos

Bot Discord completo com sistema administrativo, verificacao Roblox, tickets, CGA e mais!

## Funcionalidades

- ✅ Verificacao Roblox
- ✅ Sistema de Configuracao
- ✅ Moderacao
- ✅ Sistema de Tickets
- ✅ CGA (Corregedoria)
- ✅ Staff System
- ✅ Convocacoes
- ✅ Sistema de Ausencias

## Instalacao

1. Clone: `git clone https://github.com/kauearaujo2018-ai/legacy-bot.git`
2. Instale: `npm install`
3. Configure .env
4. Setup: `npm run setup`
5. Registre: `npm run register`
6. Inicie: `npm start`

## Requisitos

- Node.js 18+
- PostgreSQL ou SQLite
- Token Discord Bot
